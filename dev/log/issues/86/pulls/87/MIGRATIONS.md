## CI repair continuation

The fresh npm registry lookup still resolves latest to 12.2.2. glob's v14 changelog and minimatch's v11 changelog are retained in `research/*-changelog-restart.md`: glob changes its walker collection and matcher APIs; minimatch removes AST, makeRe, regexp and matchOne. npm's internal consumers still depend on those removed APIs. Replacing the bundled child majors without migrating/testing npm would create an unsupported CLI distribution. The fallback preserves the official bundle and labels its two advisories unresolved; it does not claim to complete their migration.

Native `RegExp.escape` replaces the incomplete per-dot escaping in Rust/C# release scripts. Standard URL parsers replace hostname substring checks in JavaScript and both Python release paths. command-stream's argument quoting replaces manual double-quote escaping for version commits; execFileSync replaces Rust's git identity shell command and avoids logging identity values. The identifier sanitizer uses two linear scans to trim underscores while preserving the existing fallback and all meaningful identifier characters.
